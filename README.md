# 灵动表情 Prompt 实验室

一个面向人物 IP 表情分析的前端工作台，用来把单帧或连续多帧表情素材沉淀为统一结构的 Prompt 结果。

项目重点不是替换人物 IP，也不是跨角色迁移动作，而是围绕当前输入角色，稳定拆解：

- 人物身份保持特征；
- 主要情绪、次级情绪与情绪强度；
- 眼睛、眉毛、嘴部、头部和附加面部细节；
- 起始状态、过渡状态、目标状态；
- 动作幅度、方向、速度、左右差异和最终停留状态；
- 初始 Prompt、复刻检查与最终优化 Prompt。

## 功能特点

- 支持单帧表情与连续状态两种分析模式；
- 支持上传 PNG、JPG、WebP、GIF 表情素材；
- 自动生成结构统一的分析字段，便于后续进入“情绪-动作-Prompt”数据库；
- 内置角色一致性约束，强调脸型、五官比例、发型和画风不漂移；
- 输出包含动作参数描述、动态关键词、初始 Prompt 和最终优化 Prompt；
- 简约浅色界面，适合批量整理表情素材。

## 本地运行

这是一个静态前端项目，核心页面位于 `dist/`，可以直接用任意静态服务器打开。

在 PowerShell 中运行：

```powershell
cd "E:\广研一个月\新任务\表情IP工作流"
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

然后访问：

```text
http://127.0.0.1:4173/
```

如果已经安装 Node.js，也可以用其他静态服务器托管 `dist/` 目录。

## 目录结构

```text
dist/
├── index.html    # 页面结构
├── styles.css    # 简约浅色界面样式
└── app.js        # 上传、状态切换、结构化结果生成逻辑
```

仓库中保留了 Sites/Vinext 相关配置文件，方便从同一工作流继续托管或迁移；当前可直接使用的前端代码以 `dist/` 为准。

## 使用流程

1. 选择单帧表情或连续状态模式；
2. 上传当前人物 IP 的表情素材；
3. 可选填写 IP 名称与补充观察重点；
4. 点击“开始动作拆解”；
5. 复制生成的结构化分析与最终优化 Prompt。

## 输出格式

工具会按照固定字段组织结果：

- 当前 IP 特征；
- 情绪识别；
- 动作拆解；
- 灵动感核心；
- 动态关键词；
- 动作参数描述；
- 初始 Prompt；
- 复刻检查；
- 最终优化 Prompt。

## 适用场景

- 动漫、游戏、虚拟角色表情素材整理；
- 表情包、角色设定、分镜动作分析；
- 图像生成或动画生成 Prompt 模板沉淀；
- 批量建立人物表情动作数据库。

## 注意事项

- 每次任务只围绕当前输入的人物 IP 分析；
- 不主动改变角色身份、画风、脸型和主要五官；
- 连续多帧素材应重点关注动作先后顺序和情绪过渡；
- 上传图片仅在浏览器本地用于预览和分析文本生成，不依赖远程素材库。
